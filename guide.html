📚 이북 리더 사용 가이드

🎯 도서 목록 보기

1단계: 화면 우측 상단의 "📚 도서" 버튼 클릭
위치: 진행률 표시 → 초록색 "도서" 버튼 → 회색 "설정" 버튼

➕ 새 도서 추가하기

방법 1: URL에서 다운로드

1. "도서" 버튼 → "📥 도서 다운로드" 클릭
2. 텍스트 파일 URL 입력
예시: https://www.gutenberg.org/files/11/11-0.txt
3. 도서 제목 입력 (선택사항)
4. 다운로드 완료!

방법 2: 텍스트 직접 추가

1. "도서" 버튼 → "➕ 텍스트 추가" 클릭
2. 도서 제목 입력
3. 내용 입력 또는 복사/붙여넣기
4. 확인!

📖 도서 읽기

1. "도서" 버튼으로 도서 목록 열기
2. 읽고 싶은 도서 찾기
3. "📖 읽기" 버튼 클릭
4. 도서가 열립니다!

🎨 독서 설정

폰트 크기 조절

• A⁻ 버튼: 글자 크기 축소
• A⁺ 버튼: 글자 크기 확대
• ⟲ 버튼: 기본 크기로 초기화
• 키보드: +, -, 0 키

테마 변경

1. "⚙️ 설정" 버튼 클릭
2. "테마" 드롭다운 선택
• 라이트: 밝은 배경
• 다크: 어두운 배경
• 세피아: 종이책 느낌

줄/글자 간격

"설정" → "줄 간격" 또는 "글자 간격" 선택
원하는 간격으로 조절 가능

📱 페이지 이동

• ◀ 버튼 또는 ← 키: 이전 페이지
• ▶ 버튼 또는 → 키: 다음 페이지
• 모바일: 좌우 스와이프

💾 저장 및 동기화

• 도서는 자동으로 IndexedDB에 저장
• 읽기 위치 자동 저장
• 최대 100MB 저장 가능
• 오프라인에서도 읽기 가능
💡 팁:
  • 처음 사용할 때 "기본 도서"가 이미 로드되어 있습니다
  • 도서를 추가하면 목록에서 선택하여 읽을 수 있습니다
  • 마지막으로 읽던 위치로 자동 이동합니다
  • 앱을 설치하면 오프라인에서도 사용 가능합니다

🔍 문제 해결

도서 목록이 안 보여요
→ "도서" 버튼(초록색)을 클릭하세요

도서 추가가 안 돼요
→ 온라인 상태인지 확인하세요 (URL 다운로드 시)
→ 텍스트 추가는 오프라인에서도 가능합니다

앱 설치가 안 돼요
→ 페이지 강제 새로고침 (Ctrl+Shift+R)
→ HTTPS 연결 확인
→ Chrome/Edge/Safari 최신 버전 사용
