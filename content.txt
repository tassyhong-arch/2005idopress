# 오프라인 이북 리더에 오신 것을 환영합니다!

## 시작하기

이 앱은 Progressive Web App(PWA)로 제작되었습니다.
인터넷이 없어도 저장된 도서를 읽을 수 있습니다.

### 주요 기능

1. **오프라인 독서**: 인터넷 연결 없이 도서 읽기
2. **도서 다운로드**: 온라인 상태에서 도서 저장
3. **여러 도서 관리**: 여러 권의 도서 저장 및 관리
4. **읽기 설정**: 폰트 크기, 테마, 줄 간격 조절

### 사용 방법

1. 온라인 상태에서 "도서 관리" 버튼 클릭
2. "도서 다운로드"로 URL에서 도서 다운로드
3. 또는 "텍스트 추가"로 내용 직접 입력
4. 오프라인에서도 자유롭게 읽기!

### 앱 설치

- **Android**: Chrome 브라우저에서 "앱 설치" 버튼 클릭
- **iOS**: Safari에서 공유 버튼 → "홈 화면에 추가"
- **PC**: Chrome/Edge에서 주소창의 "설치" 아이콘 클릭
