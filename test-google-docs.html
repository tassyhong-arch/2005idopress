📚 Google Docs 다운로드 테스트

이북 리더에서 Google Docs 문서를 다운로드하는 기능을 테스트합니다.

🔗 테스트 URL

주생전 (한국 고전소설):

💡 사용 방법:
  1. "URL 변환" 버튼을 클릭하면 Google Docs URL이 내보내기 형식으로 변환됩니다
  2. "다운로드 테스트" 버튼을 클릭하면 실제로 문서를 다운로드합니다
  3. 변환된 URL을 복사해서 이북 리더의 "도서 다운로드"에서 사용할 수 있습니다

📋 이북 리더에서 사용하기

  1. 이북 리더로 돌아가기
  2. "📚 도서" 버튼 클릭
  3. "도서 다운로드" 선택
  4. 위의 Google Docs URL 붙여넣기
  5. 제목 입력: 주생전
  6. 완료! 📖
