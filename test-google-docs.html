📋 Google Docs 공유 설정 방법

1단계: Google Docs 문서 열기
2단계: 우측 상단 "공유" 버튼 클릭
3단계: "일반 액세스" 섹션에서
4단계: "링크가 있는 모든 사용자" 선택
5단계: 권한을 "뷰어" 또는 "댓글 작성자"로 설정
6단계: "완료" 클릭

🔍 내보내기 URL 형식

원본 URL:

https://docs.google.com/document/d/[DOCUMENT_ID]/edit?usp=sharing

내보내기 URL:

https://docs.google.com/document/d/[DOCUMENT_ID]/export?format=txt
